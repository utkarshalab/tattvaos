# lib/ufont — Font Library

The **`lib/ufont`** library is the font library of Utkarsha OS: reading font
files, choosing a face for a family, weight and style, shaping text into
positioned glyphs, and handing out glyph outlines and metrics. The Canvas display server draws SVG text with
it; the web engine, terminals and document viewers are meant to use the
same library rather than each carrying a font reader.

ufont does not rasterize. Outlines go into [`lib/ugfx`](../ugfx/) paths,
so text is filled, transformed, clipped and anti-aliased like any other
drawing. Shaping follows HarfBuzz step for step (OpenType GSUB / GPOS, the
Indic shaper for the nine Indic scripts, the Arabic and Hebrew shapers,
right-to-left runs, the fallbacks for fonts without layout tables), checked
glyph for glyph against a model that is itself checked against HarfBuzz. ufont carries the Unicode data shaping
needs (`layout/ucd.asm`, generated); `lib/str`'s tables could not be used
as they are (duplicate symbols, a file that does not assemble, not
position independent).

## 1. Layout

```
lib/ufont/
├── include/
│   └── ufont.inc         ← layouts: UfontFont, UfontSet / UfontFace, UfontStd
├── sfnt/
│   └── sfnt.asm          ← TrueType reading: tables, cmap, advances, metrics, outlines
├── match/
│   └── fontset.asm       ← font sets: CSS family lists, weight / style; ugfx's font callback
├── layout/               ← text shaping
│   ├── shape.asm         ← ufont_shape: the pipeline
│   ├── shape.inc         ← the shaping state and plan records
│   ├── buffer.asm        ← the glyph buffer: input / output sides, clusters
│   ├── unicode.asm       ← character properties, decomposition, composition
│   ├── normalize.asm     ← normalization against the font, variation selectors
│   ├── otl.asm           ← reading GDEF / GSUB / GPOS: coverage, classes, scripts, features
│   ├── map.asm           ← the plan: features, masks, stages, lookups
│   ├── apply.asm         ← applying lookups: skipping, matching, ligatures, contexts
│   ├── gsub.asm          ← substitutions
│   ├── gpos.asm          ← positioning
│   ├── indic.asm         ← the Indic shaper (Devanagari ... Malayalam)
│   ├── arabic.asm        ← the Arabic shaper (joining, fallback shaping) and the Hebrew shaper
│   ├── fallback.asm      ← mark positioning for fonts without GPOS
│   ├── ucd.asm           ← Unicode data (generated by tools/ucd_table.py)
│   └── indic_table.asm   ← Indic categories and the syllable automaton (generated)
├── fonts/                ← the shipped fonts (Noto, Liberation), their licences, README.md
├── tools/                ← development machine only
│   ├── fontmodel.py      ← the font reader modelled over fontTools
│   ├── shapemodel.py     ← shaping modelled on HarfBuzz (indic.py: the Indic shaper,
│   │                       arabic.py: the Arabic and Hebrew shapers)
│   ├── syllable.py       ← syllable grammars compiled to automata
│   ├── ucd_table.py      ← generates layout/ucd.asm, ucd_data.py
│   └── indic_table.py    ← generates layout/indic_table.asm, indic_data.py
└── tests/host/
    ├── host_font.asm     ← host tool: glyphs, metrics, matching
    ├── font_check.py     ← checks host_font against fontmodel
    ├── host_shape.asm    ← host tool: shaping
    └── shape_check.py    ← checks host_shape against shapemodel (and it against HarfBuzz)
```

Programs assemble the sources into their own builds (Canvas does through
`UFONT_DIR`, as it does for ugfx); they provide `arena_alloc` and link
ugfx's path code. Include paths: `lib/ufont/include` and `lib/ugfx/include`.

## 2. Interface

### Fonts (sfnt/sfnt.asm)

| Call | Does |
|---|---|
| `ufont_open(arena, data, length)` | index a TrueType font (the bytes stay the caller's) → `UfontFont*` or 0 |
| `ufont_glyph(font, code point)` | the glyph for a character → glyph id, 0 when the font has none |
| `ufont_advance(font, glyph)` | its advance width in font units |
| `ufont_metrics(font)` | units per em, ascent, descent (font units) |
| `ufont_extents(font, glyph)` | its box: x bearing (from hmtx), top, width, height (negative); zeros for an empty glyph |
| `ufont_outline(font, glyph, path, scale, arena)` | its outline into a ugfx path at `scale` pixels per font unit, y down, origin on the baseline → 0, -EINVAL, -ENOMEM |

What is read: the table directory and head, maxp, hhea, hmtx, loca, glyf
and cmap, every offset and length checked against the data first; cmap
format 12 (preferred) or 4 on a Unicode encoding; simple glyphs (flag
repeats, short and long coordinates, implied on-curve points between
off-curve ones) and composite glyphs (offsets, a scale, x and y scales or
a 2 x 2 matrix, scaled offsets when flagged; point-matched components at
offset 0), six levels deep at most, 16384 points per glyph at most; the
layout tables GDEF, GSUB, GPOS and kern, and cmap format 14 (variation
sequences) for shaping. Not read: hinting instructions, CFF outlines,
variations, colour glyphs.

### Shaping (layout/shape.asm)

| Call | Does |
|---|---|
| `ufont_shape(font, arena, code points, count, script, language)` | a run of characters as positioned glyphs → `UfontGlyph` records (glyph, cluster, x / y advance, x / y offset; font units, y up) and their count; 0 when out of memory |

`script` is an ISO 15924 tag (`'Deva'`, `'Latn'`) or 0 to take it from the
text; `language` an OpenType language system tag or 0. The pipeline is
HarfBuzz's: grapheme clusters; the script's tags in the font (the new
Indic tags first) and language system; the feature plan (common and
horizontal features, fractions around U+2044; for Devanagari, Bengali,
Gurmukhi, Gujarati, Oriya, Tamil, Telugu, Kannada and Malayalam the Indic
shaper's stages unless the font only has DFLT / latn for them; for Arabic
and Syriac the Arabic shaper's forms, each its own stage; for Hebrew the
Hebrew shaper); right-to-left scripts (Arabic, Hebrew, Syriac, Thaana and
the other right-to-left scripts) run with rtla / rtlm, mirrored
characters (brackets) taking their mirror where the font has it; vowel
constraints; normalization against the font (decompose what the font
lacks, marks in combining-class order - Arabic modifier marks first,
Hebrew's points as Hebrew orders them - recompose, for Hebrew in fonts
without mark positioning into the presentation forms; variation
selectors; spaces and the non-breaking hyphen the font lacks); Arabic
joining (each letter's form from Unicode's joining types, transparent
marks skipped); GSUB (all eight lookup types, contexts, the skipping
rules for marks, joiners and ignorables), and for an Arabic font without
the form features the fallback - single substitutions to the
presentation forms and the lam-alef and other ligatures the font maps;
advances and space widths; GPOS (single, pair, cursive in both
directions, mark to base / ligature / mark, contexts; the Hebrew shaper
only from a font's `hebr` script) or the legacy kern table (only where
GPOS does not kern the script, not for Indic; right to left on visual
pairs); mark widths; default ignorables drawn as zero-width spaces; mark
and cursive offsets chained; without GPOS, marks placed around their
base by combining class from the glyphs' boxes (stacked a sixteenth of
the em apart, over a ligature's component); right to left, the glyphs
returned in visual order (clusters descending). Glyph classes come from
GDEF, or from Unicode for fonts without one. A runaway font is
cut off (recursion 64 deep and 1024 x the text in all; the buffer at most
64 x the text).

### Font sets (match/fontset.asm)

| Call | Does |
|---|---|
| `ufont_set_init(set, arena)` | an empty set (`UfontSet_SIZE` bytes, up to 64 faces) |
| `ufont_set_add(set, data, length, family, weight, italic)` | open a font and add it under a family name → 0, -EINVAL, -ENOMEM |
| `ufont_set_face(set, UgfxSvgFont*)` | the face for a CSS `font-family` list, weight and style → `UfontFace*` |
| `ufont_svg_font` | lib/ugfx's SVG font callback (`UgfxSvg_font_fn`, user = the set): advances, outlines, ascent / descent; glyph keys from `ufont_svg_shape` |
| `ufont_svg_shape` | lib/ugfx's SVG shaping callback (`UgfxSvg_shape_fn`): a run split by face and script, each part through `ufont_shape` |
| `ufont_standard`, `ufont_standard_count` | the shipped fonts: file name, family, weight, italic (`UfontStd`) |

Matching: the family list is read as CSS has it (comma separated, quoted
or not, without case). Generic and common names stand for the shipped
families — `sans-serif`, `system-ui`, `ui-sans-serif`, `cursive`, `fantasy`:
Noto Sans; `serif`, `ui-serif`: Noto Serif; `monospace`, `ui-monospace`:
Noto Sans Mono; Arial, Helvetica, Helvetica Neue, Arimo: Liberation Sans;
Times New Roman, Times, Tinos: Liberation Serif; Courier New, Courier,
Cousine: Liberation Mono. The first name with a face in the set wins,
else Noto Sans, else the first face. Within a family the style is matched
first, then the weight (bold from 600). A character the face lacks comes
from Noto Sans in the same style, else from the first face in the set
that has it (same weight and style, then same weight, then any) - so
Devanagari in any family is drawn from Noto Sans Devanagari, Arabic from
Noto Sans Arabic and Hebrew from Noto Sans Hebrew. When
shaping, marks and default ignorables stay in the face before them, and
a run is shaped in parts where the face or the script changes (common
and inherited characters joining the script before them).

Loading: a program maps each `ufont_standard` file from the fonts
directory — installed read-only at `/app/lib/ufont/fonts/` — and adds it
with its family, weight and style; the set then serves any number of
documents. Canvas hands its set to `svg_set_fonts`.

## 3. Fonts

`fonts/` holds Noto Sans, Noto Serif and Noto Sans Mono (subset to Latin,
Greek and Cyrillic with common symbols, layout tables kept), Noto Sans
and Noto Serif Devanagari, Noto Sans Bengali, Gurmukhi, Gujarati,
Oriya, Tamil, Telugu, Kannada and Malayalam, Noto Sans and Noto Naskh
Arabic and Noto Sans and Noto Serif Hebrew (unmodified) and Liberation
Sans, Serif and
Mono (unmodified, for documents naming Arial / Helvetica, Times New Roman
and Courier New, whose character widths they share). Sources, the exact
subsetting command and the licences (SIL OFL 1.1): `fonts/README.md`.

## 4. Tests

`make host-check` (needs nasm, ld, python3 with fontTools) builds
`host_font` and runs `tests/host/font_check.py`:

- every code point each shipped font maps, and some it does not: the glyph,
  the advance and the outline's verbs and points identical to fontTools'
  reading through `tools/fontmodel.py`;
- the metrics;
- 567 matching queries (family lists with generic names, aliases, quotes,
  case and unknown names, weights 100 to 900, normal / italic / oblique);
- truncated and corrupted fonts never crash the reader.

`make host-check` also builds `host_shape` and runs
`tests/host/shape_check.py`: for every shipped font, words in Latin,
Greek, Cyrillic, the Indic scripts, Arabic and Hebrew and random strings
(marks, joiners, ignorables, ligature letters, fractions; random
syllables in each Indic font's script with reph, nukta, half forms,
matras, joiners and broken clusters; random Arabic and Hebrew with
harakat, points, tatweel, joiners, digits and brackets) shaped by ufont
equal `tools/shapemodel.py` glyph for glyph, cluster for cluster, unit
for unit; Noto Sans Devanagari altered to old-spec only, DFLT only, no
GSUB and no GDEF, and Noto Sans, Noto Sans Arabic, Noto Sans Hebrew and
Noto Sans Devanagari without GPOS, GSUB, GDEF or all three (the
fallbacks) too; damaged fonts never crash it. With uharfbuzz installed the
model is compared with HarfBuzz on the same cases (HarfBuzz 12.3.2: all
equal).

Canvas's `tests/host/svg_text_check.py` checks the whole path: SVG text
decoded by Canvas with these fonts, identical to ugfx drawing the model's
calls.
